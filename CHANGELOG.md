# Changelog

## v1.7

- **Pick the variation.** Numpad 1-9 now picks a variation, and Numpad 0 replays the last voiceline
  with that variation. Other players hear the same variation.
- Voicelines played from Mordhau's own menus play normally again, with a random variation.
- The chat confirms the picked variation, and warns when a voiceline has no such variation.
- Replaying the same variation twice in a row works for other players too: they briefly hear
  another variation (about 0.1 s) before the right one.
- Removed the fixed Numpad 1-9 shortcuts (Laugh, Battlecry, Yes...).

## v1.6

- First public release. Numpad 1-9 play fixed voicelines and Numpad 0 repeats the last voiceline,
  always with its first variation. Each press cuts off the previous one.
